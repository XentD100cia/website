# XentD100cia Web Starter

Proyecto base para la web de XentD100cia con Astro + Tailwind.

## Instalar

```bash
npm install
npm run dev
```

## Sustituir imágenes

- Logo: `public/images/logo-xentd100cia.jpeg`
- Hero: crea `public/images/hero-placeholder.jpg` con una foto real de taller.

## Páginas incluidas

- Inicio
- Talleres
- OSC
- Quiénes somos
- Noticias
- Contacto
